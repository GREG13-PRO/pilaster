**Leírás:**

A Pilaster egy modern fájlkezelő Windows 11-re. Olyan, mintha a rendszer része lenne, csak gyorsabb, és sok mindent tud, ami az Intézőből hiányzik.

• Fülek a címsorban, mint az Intézőben: egy ablakban annyi mappát nyitsz meg, amennyit szeretnél.

• Oszlopnézet a macOS Finder mintájára: a mappaszerkezet vízszintesen nyílik ki.
• Keresés az almappákban is, a találatok helyével együtt.
• Színes címkék és kedvencek, egy kattintással szűrhető oldalsávval.
• Saját másolómotor: szüneteltethető, folytatható műveletek, sebesség és hátralévő idő, ütközéskezelés.
• Átlátható jobbklikk-menü a fájl adataival, gyors műveletekkel és a telepített programok bővítményeivel.
• Beépített szövegszerkesztő szintaxiskiemeléssel.
• Sötét és világos téma, választható kiemelőszín, üveghatás és finom animációk. Gyengébb gépen egy kattintással kikapcsolhatók.
• Nextcloud-, OneDrive- és WebDAV-mappák az oldalsávban.

Ingyenes és nyílt forráskódú (MIT-licenc). Nincs benne reklám, telemetria vagy fiók.

## English (en-US)

**Name:** Pilaster

**Short description (max. 100 characters):**
A fast, modern file manager for Windows 11 with tabs, dual panes, tags and column view.

**Description:**

Pilaster is a modern file manager for Windows 11. It feels like part of the system, only faster, and it does a lot of things File Explorer never did.

• Tabs in the title bar, just like File Explorer: open as many folders as you want in one window.
• Dual-pane view: copy or move to the other pane with one click, or with F5/F6.
• Column view inspired by the macOS Finder: the folder tree unfolds horizontally.
• Search that includes subfolders and shows where each result lives.
• Color tags and favorites, with one-click filtering from the sidebar.
• Its own copy engine: pause and resume, transfer speed and time remaining, conflict handling.
• A clear right-click menu with file details, quick actions and your installed apps' extensions.
• Built-in text editor with syntax highlighting.
• Dark and light themes, accent colors, glass effects and smooth animations. You can turn them off with one click on slower PCs.
• Nextcloud, OneDrive and WebDAV folders in the sidebar.

Free and open source (MIT license). No ads, no telemetry, no account.
