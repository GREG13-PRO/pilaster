Code signing policy

Last updated: October 10, 2026

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: Pilaster has applied to the SignPath Foundation's free code signing program for open-source projects. Releases are signed from the first version after approval; earlier releases are not signed.

What is signed

The Windows release builds: Pilaster.exe, the installer Pilaster.Setup.exe and Pilaster's own libraries (Pilaster.*.dll). They are built, packaged and submitted for signing by GitHub Actions, directly from the source code in this repository. Nothing is built or signed on a personal computer. Third-party libraries, such as the .NET runtime files, keep their own publisher's signature.

Team roles

  • Committers and reviewers: GREG13-PRO
  • Approvers: GREG13-PRO

Every signing request is approved by hand by an approver. All team members use multi-factor authentication for GitHub and SignPath.

Privacy

Pilaster doesn't collect or transfer personal data. It makes no network connections unless you ask for one, with a single exception: at startup it asks GitHub (api.github.com) whether a newer version is available. That request contains no personal data, and you can turn it off in Settings → Updates. A bug report is sent only when you write one and click Send. Details: privacy policy.

Kódaláírási szabályzat

Utolsó frissítés: 2026. október 10.

Az ingyenes kódaláírást a SignPath.io biztosítja, a tanúsítványt a SignPath Foundation adja ki.

Állapot: a Pilaster jelentkezett a SignPath Foundation nyílt forrású projekteknek szóló, ingyenes kódaláírási programjába. A jóváhagyás utáni első verziótól kezdve a kiadások alá vannak írva; a korábbiak nem.

Mi van aláírva

A Windows-kiadások: a Pilaster.exe, a Pilaster.Setup.exe telepítő és a Pilaster saját könyvtárai (Pilaster.*.dll). Ezeket a GitHub Actions fordítja, csomagolja és küldi aláírásra, közvetlenül ennek a tárolónak a forráskódjából. Személyes számítógépen semmi nem készül és nem kerül aláírásra. A külső könyvtárak, például a .NET futtatókörnyezet fájljai, a saját kiadójuk aláírását viselik.

Szerepkörök

  • Fejlesztők és ellenőrzők: GREG13-PRO
  • Jóváhagyók: GREG13-PRO

Minden aláírási kérést egy jóváhagyó kézzel hagy jóvá. A csapat minden tagja kétlépcsős azonosítást használ a GitHubon és a SignPathon.

Adatvédelem

A Pilaster nem gyűjt és nem továbbít személyes adatot. Hálózati kapcsolatot csak akkor létesít, ha kéred, egyetlen kivétellel: induláskor megkérdezi a GitHubot (api.github.com), van-e újabb verzió. Ez a kérés nem tartalmaz személyes adatot, és a Beállítások → Frissítések alatt kikapcsolható. Hibabejelentés csak akkor megy el, ha megírod és a Küldés gombra kattintasz. Részletek: adatvédelmi nyilatkozat.
