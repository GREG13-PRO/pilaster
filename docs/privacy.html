Privacy Policy

Last updated: September 26, 2026

Pilaster doesn't collect, sell or share any personal data. It has no telemetry, no analytics, no ads and no user accounts. Your files and settings never leave your PC.

What stays on your device

Pilaster is a file manager. To do its job it reads the folders and files you browse, and stores these on your PC only:

  • settings, tags, favorites and quick-access entries;
  • caches that make browsing faster (for example folder sizes);
  • diagnostic log files, which help troubleshoot crashes.

The Microsoft Store version keeps this data in the app's private storage, and Windows removes it when you uninstall the app. The version downloaded from GitHub keeps it in %APPDATA%\Pilaster, or next to the program in portable mode.

Network connections

The Microsoft Store version makes no network connections of its own. Updates are delivered by the Microsoft Store.

The version downloaded from GitHub checks for new versions using the public GitHub API (api.github.com). The request contains no personal data, but, like any web request, GitHub can see your IP address. See GitHub's privacy statement.

Bug reports

A bug report is only sent if you write one and click Send. It contains your description, the app version and the Windows version. If you tick the boxes, it also includes a screenshot of the Pilaster window and a recent log excerpt. Reports go to the developer only and are used only to fix bugs.

Third-party components

Like File Explorer, Pilaster shows the context-menu entries that other installed programs register (for example archivers or cloud storage clients). Those programs run under their own privacy policies. Pilaster doesn't send them any data beyond the files you choose to act on.

Children

Pilaster doesn't knowingly collect any information from anyone, including children under 13.

Changes and contact

If this policy changes, the updated version will be published on this page with a new date. Questions: pilaster-explorer@proton.me, or GitHub Issues.

Adatvédelmi nyilatkozat

Utolsó frissítés: 2026. szeptember 26.

A Pilaster semmilyen személyes adatot nem gyűjt, nem ad el és nem oszt meg. Nincs benne telemetria, statisztikagyűjtés, reklám vagy felhasználói fiók. A fájljaid és a beállításaid nem hagyják el a gépedet.

Ami a gépeden marad

A Pilaster fájlkezelő. A működéséhez olvassa a mappákat és fájlokat, amelyeket megnyitsz, és kizárólag a saját gépeden tárolja a következőket:

  • beállítások, címkék, kedvencek és gyorselérés-elemek;
  • a böngészést gyorsító átmeneti adatok (például mappaméretek);
  • diagnosztikai naplófájlok, amelyek az összeomlások kivizsgálását segítik.

A Microsoft Store-verzió ezeket az alkalmazás saját, elkülönített tárhelyén tartja, amelyet a Windows az eltávolításkor töröl. A GitHubról letöltött verzió a %APPDATA%\Pilaster mappát használja, hordozható módban pedig a program melletti mappát.

Hálózati kapcsolatok

A Microsoft Store-verzió magától nem létesít hálózati kapcsolatot. A frissítéseket a Microsoft Store telepíti.

A GitHubról letöltött verzió a nyilvános GitHub API-n (api.github.com) nézi meg, van-e újabb verzió. A kérés nem tartalmaz személyes adatot, de mint minden webes kérésnél, a GitHub látja az IP-címedet. Lásd a GitHub adatvédelmi nyilatkozatát.

Hibabejelentés

Hibabejelentés csak akkor megy el, ha megírod és a Küldés gombra kattintasz. Ez a leírásodat, az alkalmazás és a Windows verziószámát tartalmazza. Ha bejelölöd, egy képernyőképet is a Pilaster ablakáról, valamint egy friss naplórészletet. A bejelentést csak a fejlesztő látja, és kizárólag hibajavításra használja.

Más programok

Az Intézőhöz hasonlóan a Pilaster is megjeleníti a jobbklikk-menüben a más telepített programok (például tömörítők, felhőtárhely-kliensek) által regisztrált elemeket. Ezekre a programokra a saját adatvédelmi szabályaik vonatkoznak. A Pilaster nem ad át nekik adatot azokon a fájlokon kívül, amelyeken a műveletet végrehajtod.

Gyermekek

A Pilaster senkitől, így 13 év alatti gyermekektől sem gyűjt tudatosan semmilyen adatot.

Változások és kapcsolat

Ha a nyilatkozat változik, a frissített változat új dátummal ezen az oldalon jelenik meg. Kérdés esetén: pilaster-explorer@proton.me, vagy GitHub Issues.
